Backend

The framework supports three optional files in your project root that run in Electron's main process. Each must export default a function.

File When it runs Context
backend.js Every startup { ipc, app, Menu }
init.js Once on first launch { ipc, app, Menu }
update.js When version in package.json changes { ipc, app, Menu, from, to }

Startup Sequence

  1. Framework init — JSON DB and SQL DB systems made available — runs every startup
  2. init.js — runs only on first launch, or update.js — runs only when version changes
  3. Schema sync — creates/migrates tables from schema/ files — runs every startup
  4. backend.js — runs every startup
  5. Window creation — app window opens

backend.js

Runs every startup. Use it for custom IPC handlers, native menus, deep link handling, or any server-side logic.

export default ({
  ipc,
  app,
  Menu
}) => {
  // Custom IPC handler - call from renderer via ipcRenderer
  ipc.handle('my-channel', async (event, data) => {
    const value = await api.jsonDB('settings').get('someKey');
    return {
      result: 'ok',
      value
    };
  });
};

The function receives:

Argument What it is
ipc Electron's ipcMain
app Electron's app instance
Menu Electron's Menu class — for building native menus

init.js

Runs once on the very first app launch. Use it to create database tables, seed initial data, or perform one-time setup. Receives the same { ipc, app, Menu } context. 

export default ({
  ipc,
  app,
  Menu
}) => {
  api.sqlQuery('myapp', 'CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL, email TEXT)');
};

update.js

Runs when the version in your package.json changes from the previously stored version. Receives from and to version strings in addition to the standard context:

export default ({
  from,
  to
}) => {
  if (from === '1.0.0') {
    api.sqlQuery('myapp', 'ALTER TABLE users ADD COLUMN phone TEXT');
  }
};

API

The global api object is available in all three backend files with the same surface as the renderer — jsonDB, sqlQuery, window, notification, and more. See the API page for the full reference.

Deep Links — app.on('open-link')

The framework automatically registers your protocolName with the OS. Clicking a my-app:// link anywhere opens your app and fires open-link — on all platforms, no per-platform branching needed: 

export default ({
  ipc,
  app
}) => {
  app.on('open-link', url => {
    // url = 'my-app://some/path?foo=bar'
    const parsed = new URL(url);
    console.log(parsed.pathname, parsed.searchParams);
  });
};

File Associations — app.on('open-path')

Register file type associations at install time via electron-builder, then handle them in backend.js. Works on all platforms with a single event: 

export default ({
  ipc,
  app
}) => {
  app.on('open-path', filePath => {
    // filePath = '/Users/alice/docs/file.myext'
    ipc.emit('file-opened', filePath);
  });
};

Register the file type in your electron-builder config:

{
  "fileAssociations": [{
    "ext": "myext",
    "name": "My Document",
    "role": "Editor"
  }]
}

Mac Menu Bar

On macOS, apps have a system menu bar at the top of the screen. Use Menu from the backend hook to build one. This replaces Electron's default menu. Combine with hide-mac / show-mac CSS classes to swap the in-window dropdown for the native menu bar on Mac. 

export default ({ app, Menu }) => {

  const isMac = process.platform === "darwin";
  if(!isMac) return;

  const menu = Menu.buildFromTemplate([
    {
      label: app.getName(),
      submenu: [
        { role: "about" },
        { type: "separator" },
        { role: "quit" },
      ],
    },
    {
      label: "File",
      submenu: [
        { label: "New Window", accelerator: "CmdOrCtrl+N" },
        { role: "close" },
      ],
    },
    {
      label: "Edit",
      submenu: [
        { role: "undo" }, { role: "redo" },
        { type: "separator" },
        { role: "cut" }, { role: "copy" }, { role: "paste" },
        { role: "selectAll" },
      ],
    },
  ]);

  Menu.setApplicationMenu(menu);

};

See Electron's Menu and MenuItem docs for all available roles and options.

Quit & Cleanup

export default ({
  ipc,
  app
}) => {
  app.on('before-quit', () => {
    // cleanup before exit
    api.jsonDB('settings').set('lastSession', Date.now());
  });
  app.on('open-link', url => {
    /* ... */ });
  app.on('open-path', filePath => {
    /* ... */ });
};

Context Menu

The framework automatically shows a native context menu on right-click with smart defaults: Cut/Copy/Paste on editable inputs, Copy on selected text, and Inspect Element in dev mode. No setup needed.

To add extra items for a specific element, call api.contextMenu.show(items) in its contextmenu handler. Register a global click handler once with api.contextMenu.onClick(cb):

// Register click handler once (e.g. in app.html script)
api.contextMenu.onClick(id => {
  if(id === "delete") handleDelete();
  if(id === "rename") handleRename();
});

// Add items for a specific element
document.getElementById("my-item").addEventListener("contextmenu", () => {
  api.contextMenu.show([
    { id: "rename", label: "Rename" },
    { id: "delete", label: "Delete" },
  ]);
});

Extra items appear above the framework defaults. Each item object supports any Electron MenuItem field except click (use onClick instead).
