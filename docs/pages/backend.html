Backend

If backend.js exists in your project root, it runs in Electron's main process at startup. This gives you access to Node.js APIs, the file system, native modules, and Electron's IPC system.

backend.js Template

export default ({ db, ipc, app, Menu }) => {

  // Custom IPC handler — call from renderer via ipcRenderer
  ipc.handle("my-channel", async (event, data) => {
    const value = db.get("settings", "someKey");
    return { result: "ok", value };
  });

};

The function receives:

Argument What it is
dbThe database instance (table name is always the first argument)
ipcElectron's ipcMain
appElectron's app instance
MenuElectron's Menu class — for building native menus

Deep Links — app.on('open-link')

The framework automatically registers your protocolName with the OS. Clicking a my-app:// link anywhere opens your app and fires open-link — on all platforms, no per-platform branching needed: 

export default ({ db, ipc, app }) => {

  app.on("open-link", url => {
    // url = "my-app://some/path?foo=bar"
    const parsed = new URL(url);
    console.log(parsed.pathname, parsed.searchParams);
  });

};

File Associations — app.on('open-path')

Register file type associations at install time via electron-builder, then handle them in backend.js. Works on all platforms with a single event: 

export default ({ db, ipc, app }) => {

  app.on("open-path", filePath => {
    // filePath = "/Users/alice/docs/file.myext"
    ipc.emit("file-opened", filePath);
  });

};

Register the file type in your electron-builder config:

{
  "fileAssociations": [{
    "ext": "myext",
    "name": "My Document",
    "role": "Editor"
  }]
}

Mac Menu Bar

On macOS, apps have a system menu bar at the top of the screen. Use Menu from the backend hook to build one. This replaces Electron's default menu. Combine with hide-mac / show-mac CSS classes to swap the in-window dropdown for the native menu bar on Mac. 

export default ({ app, Menu }) => {

  const isMac = process.platform === "darwin";
  if(!isMac) return;

  const menu = Menu.buildFromTemplate([
    {
      label: app.getName(),
      submenu: [
        { role: "about" },
        { type: "separator" },
        { role: "quit" },
      ],
    },
    {
      label: "File",
      submenu: [
        { label: "New Window", accelerator: "CmdOrCtrl+N" },
        { role: "close" },
      ],
    },
    {
      label: "Edit",
      submenu: [
        { role: "undo" }, { role: "redo" },
        { type: "separator" },
        { role: "cut" }, { role: "copy" }, { role: "paste" },
        { role: "selectAll" },
      ],
    },
  ]);

  Menu.setApplicationMenu(menu);

};

See Electron's Menu and MenuItem docs for all available roles and options.

Context Menu

The framework automatically shows a native context menu on right-click with smart defaults: Cut/Copy/Paste on editable inputs, Copy on selected text, and Inspect Element in dev mode. No setup needed.

To add extra items for a specific element, call window.api.contextMenu.show(items) in its contextmenu handler. Register a global click handler once with window.api.contextMenu.onClick(cb):

// Register click handler once (e.g. in app.html script)
window.api.contextMenu.onClick(id => {
  if(id === "delete") handleDelete();
  if(id === "rename") handleRename();
});

// Add items for a specific element
document.getElementById("my-item").addEventListener("contextmenu", () => {
  window.api.contextMenu.show([
    { id: "rename", label: "Rename" },
    { id: "delete", label: "Delete" },
  ]);
});

Extra items appear above the framework defaults. Each item object supports any Electron MenuItem field except click (use onClick instead).
