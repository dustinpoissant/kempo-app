Icons

Icons are inline SVGs loaded by <k-icon name="...">. The framework searches three directories in order — first match wins:

  1. /icons/ — your project's icons/ directory (custom overrides)
  2. /framework/icons/ — kempo-app built-ins (window controls)
  3. /modules/kempo-ui/icons — kempo-ui's bundled icon set

Finding Icons — Interactive CLI

kempo-ui bundles the Google Material Symbols icon set. The easiest way to find and download icons is the interactive CLI:

npx kempo-icon

This opens a searchable list — type to filter, select an icon, and it downloads the SVG into your icons/ directory automatically.

Finding Icons — Two-Step CLI

For scripting or non-interactive use, search and download separately:

# Search for icons by keyword (prints matching names)
npx kempo-listicons settings
npx kempo-listicons arrow
npx kempo-listicons home

# Download an icon SVG into your icons/ directory
npx kempo-geticon settings   # → icons/settings.svg
npx kempo-geticon home       # → icons/home.svg

After running kempo-geticon, the SVG is in your icons/ folder and immediately usable.

Custom Icons

Place any .svg file in your icons/ directory:

icons/
  my-logo.svg
  custom-arrow.svg

Then reference by filename (no extension):

<k-icon name="my-logo"></k-icon>

SVGs should have a viewBox attribute. fill is set to currentColor automatically so icons inherit the text color.

Placing an icon in icons/ also overrides any same-named built-in icon from kempo-app or kempo-ui.

Sizing & Color

<!-- Size via CSS -->
<k-icon name="settings" style="width:24px; height:24px"></k-icon>

<!-- Color inherits from text color -->
<span class="tc-primary">
  <k-icon name="settings"></k-icon>
</span>
