Routing

kempo-app uses a hash router. Hash routes map directly to files in your pages/ directory.

URL hash File loaded
#/pages/index.html
#/settingspages/settings.html
#/any-namepages/any-name.html

How to create a new page

  1. Create the page file in the pages directory. 
    <h1>Page 1</h1>
  2. Link to the page usign the hash router in another page (or shell or titlebar). 
    <a href="#/page1">Go to page 1</a>

Detecting a page change

window.route is always available and updated on every navigation. It contains { path, params }.

Query params are parsed automatically: #/routing?tab=advanced&debug=true → window.route.params = { tab: "advanced", debug: "true" }

Listen for the routechange event on window to react to navigation changes. The event fires after window.route is updated. Use this instead of the native hashchange event, which fires before window.route is updated.

window.addEventListener("routechange", e => {
  console.log(e.detail.path, e.detail.params);
});

External links

Links with target="_blank" automatically open in the system's default browser instead of inside the app.

<a href="https://example.com" target="_blank">Open externally</a>

From JavaScript, use window.open() — the framework intercepts it and routes it to the system browser the same way.

window.open("https://example.com");

To open a new instance of the app itself, use window.api.window.new(). Pass an optional hash to open at a specific route.

window.api.window.new();            // opens at #/
window.api.window.new("#/settings"); // opens at #/settings
