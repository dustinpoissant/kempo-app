LLM Interact Tools

kempo-app ships a kempo-interact CLI that lets an LLM (or you) inspect and drive the running app live via Chrome DevTools Protocol. Start the app in dev mode first: 

npm run dev

This starts the app with DevTools open and CDP listening on port 9222.

Interact Commands

Always run structure or dom first to understand the page before clicking.

Command What it does
structureLists buttons, inputs, links, selects
domFull page HTML
screenshot [path]Takes a screenshot (saves to screenshot.png)
navigate <path>Navigate to a route, e.g. /settings
click <selector>Click a CSS selector
click-text <text>Click the first element containing this text
type <sel> <text>Type into an input
eval <js>Evaluate JavaScript in the renderer
titleGet the current page title
urlGet the current URL

Example Session

# 1. Get an overview of the current page
npm run interact -- structure

# 2. Take a screenshot
npm run interact -- screenshot

# 3. Navigate to a page
npm run interact -- navigate /settings

# 4. Read the database
npm run interact -- eval "await api.jsonDB('settings').get()"

# 5. Set a value
npm run interact -- eval "await api.jsonDB('settings').set('theme', 'dark')"

# 6. Click something
npm run interact -- click-text "Save"

# 7. Check the current route
npm run interact -- eval "window.route"

Creating a SKILL.md for Your App

Give your LLM full context about your app by creating a skill file at .github/skills/my-app.md. GitHub Copilot reads skills automatically and uses them when working in your project. 

# My App — Copilot Skill

## Project
This is a kempo-app Electron desktop app.
Run `npm run dev` to start it in dev mode, then use
`npm run interact -- <cmd>` to inspect and interact.

## Pages
- Home (#/) — dashboard overview
- Settings (#/settings) — user preferences and theme

## Interact Workflow
Always run `structure` first, then use other commands.

    npm run interact -- structure
    npm run interact -- screenshot
    npm run interact -- navigate /settings
    npm run interact -- eval "await api.jsonDB('settings').get()"

## Database Schema
- `theme` — "light" | "dark" | "auto"
- `username` — string

## Components Used
k-card, k-toggle, k-theme-switcher (imported in app.js)

The more context you give the LLM about your app's structure and data, the more effectively it can build and debug it.
