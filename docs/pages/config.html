Configuration

All app configuration lives in the kempo-app field of your package.json.

Example

{
  "kempo-app": {
    "appName": "My App",
    "appIcon": "media/icon.png",
    "protocolName": "my-app",
    "shell": "shell.html",
    "titlebar": "titlebar.html",
    "pages": "pages"
  }
}

Options

Key Description Default
appNameDisplay name shown in the titlebar and window titlename field, then "Kempo App"
appIconPath to the app icon (relative to project root)none
protocolNameCustom protocol scheme name — registered with the OS so protocolName:// links open the app"kempo-app"
shellDefault shell HTML file loaded for new windows"shell.html"
titlebarTitlebar HTML file, true for default, or false to disable"titlebar.html"
pagesDirectory containing page HTML fragments"pages"
