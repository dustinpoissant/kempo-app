window.api

window.api is available in any page fragment or script via Electron's contextBridge. It provides window controls, platform detection, notifications, and a file-based database.

Window Controls

Programmatic control of the window:

window.api.window.minimize()
window.api.window.maximize()  // toggles maximize / restore
window.api.window.close()

Platform Detection

const platform = await window.api.getPlatform();
// "mac" | "win" | "linux"

Notifications — window.api.notification

Use window.api.notification instead of the browser's Notification API. Because the renderer runs in a sandboxed context, the framework routes notifications through IPC to the main process, which uses Electron's native Notification class to ensure they are always delivered to the OS.

const supported = await window.api.notification.isSupported();
const id = await window.api.notification.show({ title: "Hello", body: "World" });

show() returns a notification ID. React to user interactions by listening for CustomEvents on window:

window.addEventListener("notification:click", e => console.log("clicked", e.detail.id));
window.addEventListener("notification:close", e => console.log("dismissed", e.detail.id));
window.addEventListener("notification:reply", e => console.log(e.detail.id, e.detail.reply)); // macOS inline reply

All options:

Option Type Description
titlestringNotification title. Defaults to the app name.
bodystringNotification body text.
iconstringApp-root-relative image path. Defaults to the app icon.

Window Events

The framework dispatches custom events on window that any script or component can listen for:

Event Fired when event.detail
settingchangewindow.api.db("table").set() completes{ table, key, value }
routechangeHash-based route changes{ path, params }
 
window.addEventListener("settingchange", e => {
  console.log(e.detail.table, e.detail.key, e.detail.value);
});

window.addEventListener("routechange", e => {
  console.log(e.detail.path, e.detail.params);
});
