JSON Database

api.jsonDB is a file-based JSON database. Each table is a separate JSON file stored in the OS user data directory. No schema, no setup — just pick a table name and start reading/writing.

API

// Get a table handle, then call methods on it
const settings = api.jsonDB("settings");

await settings.get()                               // all keys → { key: value, … }
await settings.get("theme")                        // one value → "dark"
await settings.set("theme", "dark")                // set a value
await settings.delete("theme")                     // remove a key
await settings.has("theme")                       // true / false
await settings.clear()                             // wipe the table

Multiple Tables

Use any table name — each one becomes its own JSON file. No need to declare tables ahead of time; they're created automatically on first write. 

// "settings" table → settings.json
const settings = api.jsonDB("settings");
await settings.set("theme", "dark")

// "contacts" table → contacts.json
const contacts = api.jsonDB("contacts");
await contacts.set("alice", { name: "Alice", email: "alice@example.com" })

// "cache" table → cache.json
const cache = api.jsonDB("cache");
await cache.set("lastFetch", Date.now())

// Each table is independent
await contacts.get()             // { alice: { name: "Alice", … } }
await cache.clear()             // only clears cache, contacts untouched

Values

Values can be any JSON-serializable type: strings, numbers, booleans, arrays, or nested objects. 

await api.jsonDB("myData").set("prefs", {
  notifications: true,
  favorites: ["home", "settings"],
  layout: { sidebar: false, compact: true }
})

const prefs = await api.jsonDB("myData").get("prefs")
console.log(prefs.layout.compact) // true

Change Events

Every .set() call dispatches a jsondb_change:{table} CustomEvent on window with the key and value in event.detail. The event name includes the table name, so you can subscribe to changes on specific tables: 

// Listen for changes to the 'settings' table
window.addEventListener('jsondb_change:settings', e => {
  console.log(e.detail.key, e.detail.value);
});
// Listen for changes to any specific table
window.addEventListener('jsondb_change:contacts', e => {
  console.log('Contact updated:', e.detail.key);
});

Backend Access

In backend.js, init.js, and update.js, the same api.jsonDB interface is available on global: 

export default ({
  ipc
}) => {
  ipc.handle('get-user', () => api.jsonDB('users').get('currentUser'));
};

Note: Change events (jsondb_change:{table}) are only dispatched in the renderer process via window. The main process does not have an event emitter — use IPC if you need to notify the renderer of backend-initiated changes.

Storage Location

Each table is stored as a separate JSON file:

Platform Path
Windows%APPDATA%\<appName>\db\*.json
macOS~/Library/Application Support/<appName>/db/*.json
Linux~/.config/<appName>/db/*.json
