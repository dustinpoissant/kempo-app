Kempo App

Electron desktop apps with no boilerplate



Routing

Kempo App is a single-page-app with "pages" that are dynamically rendered using hash routing.
Components

Kempo App uses the Kempo UI (Lit based) component library, and a few extra "App" components.
Icons

Kempo App uses locally saved svg as icons, and loads them with the <k-icon> component.
Theming

Kempo App uses Kempo-CSS Theming.
API

Built-in persistent settings DB, and window controls.
Backend

backend.js allows you to run code in the Node main process.
Testing

Write browser and Node tests for your components with shared Electron mocks.

Quick Start

Install

npm install kempo-app

Edit the default page

The install should automatically create pages/index.html — if you have post install scripts disabled or it did not create the file, simply create it, this is the only file required to make the app work.

Run it

npx kempo-app

Optional Files

Every file below is optional. The framework falls back to sensible defaults when they are absent.

shell.html — App shell

Defines the layout injected around the page content. Include a <nav> with .nav-link anchors and an <app-page> where pages render. Without it, the framework renders a plain <app-page> with no nav.

<nav class="bg-alt px bb">
  <a href="#/" class="nav-link">Home</a>
  <a href="#/about" class="nav-link">About</a>
</nav>
<app-page class="flex-1 p"></app-page>

titlebar.html — Custom titlebar

The titlebar on the top of the page. Create a titlebar.html to add menus, icons, or controls to your titlebar.

<app-titlebar class="bg-alt bb">
  <b>My App</b>
  <k-theme-switcher slot="right" class="no-drag"></k-theme-switcher>
</app-titlebar>

theme.css — Custom theming

Create your own theme for your app. Override CSS variables, override styles, or create custom styles.

:root {
  --c_primary: rgb(192, 39, 45);
}

app.js — Renderer script

Create app.js to import modules (including kempo-ui components) and write custom JavaScript that runs on the frontend of the app.

import "/modules/kempo-ui/dist/components/Card.js";
import "/modules/kempo-ui/dist/components/Toggle.js";

backend.js — Main process hook

Create backend.js to run code JavaScript in Node JS (in Electron's main process). Use it for file system access, custom IPC, native menus, or any server-side logic.

export default ({ db, ipc, app }) => {
  ipc.handle("my-channel", async (e, data) => {
    return db.get("someKey");
  });
};
