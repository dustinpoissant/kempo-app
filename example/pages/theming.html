Theming

Create theme.css in your project root to override kempo-css variables. It loads after kempo-css, so anything you set wins. The file is optional — if it doesn't exist, the framework silently ignores it.

Light / Dark Mode

kempo-css handles light/dark automatically via light-dark().

theme.css Example

/* theme.css — place in your project root */
:root {
  --c_primary:       #47848F;
  --c_primary__hover:#3a6b74;
  --c_input_accent:  #47848F;
  --c_highlight:     rgba(71, 132, 143, 0.2);
}

Common CSS Variables

Most commonly overridden variables:

Variable Controls
--c_primaryButtons, links, active nav, focus rings
--c_primary__hoverHover state for primary elements
--c_input_accentInput focus + toggle active color
--c_bgPage background
--c_bg__altNav, sidebar, card backgrounds
--c_borderBorders
--tcBase text color
--radiusBorder radius
--spacerBase spacing unit

For the full list of variables and utility classes, see the kempo-css docs.
