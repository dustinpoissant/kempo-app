API

api is a global available everywhere — renderer scripts, page fragments, backend.js, init.js, and update.js. The framework sets it up on both window (renderer) and global (main process) so you can use api.* without a prefix in any context.

Database

See the Database docs for full details.

api.jsonDB(table)

Returns a table handle for the file-based JSON database. Each table is stored as a separate JSON file. The handle provides .get(), .set(), .delete(), .has(), and .clear() methods — all async. See JSON DB docs. 

const settings = api.jsonDB('settings');
await settings.get() // all keys
await settings.get('theme') // one value
await settings.set('theme', 'dark')
await settings.delete('theme')
await settings.has('theme') // true / false
await settings.clear()
api.sqlQuery(db, sql)

Run a raw SQL query against a named SQLite database. Requires better-sqlite3 in the consumer project. SELECT returns an array of row objects; everything else returns true. Throws on error. See SQL DB docs. 

await api.sqlQuery('mydb', 'CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)')
await api.sqlQuery('mydb', "INSERT INTO users (name) VALUES ('Alice')") // true
await api.sqlQuery('mydb', 'SELECT * FROM users') // [{ id, name }, ...]

Window

api.window.minimize()

Minimize the current window to the taskbar / dock.

api.window.minimize();
api.window.maximize()

Toggle between maximized and restored window state.

api.window.maximize(); // toggles maximize / restore
api.window.close()

Close the current window. If it is the last window, the app quits (on Windows/Linux).

api.window.close();
api.window.new(options?)

Open a new app window. Pass nothing for defaults, a hash string for a specific route, or an options object to customize the shell, titlebar, or pages directory for that window. 

// Open a new window (uses default shell)
api.window.new();
// Open at a specific route
api.window.new('#/settings');
// Open with a different shell
api.window.new({
  hash: '#/editor',
  shell: 'editor-shell.html'
});
// Open with no titlebar
api.window.new({
  hash: '#/viewer',
  titlebar: false
});

The shell file is an HTML fragment that must contain an <app-page> element for the router to render pages into.

Notifications

Use api.notification instead of the browser's Notification API. Because the renderer runs in a sandboxed context, the framework routes notifications through IPC to the main process, which uses Electron's native Notification class to ensure they are always delivered to the OS.

api.notification.show(opts)

Show a native OS notification. Returns a notification ID that can be used to identify which notification the user interacted with. 

const id = await api.notification.show({
  title: 'Download Complete',
  body: 'report.pdf has been saved.',
  icon: 'media/icon.png'
});

All options:

Option Type Description
titlestringNotification title. Defaults to the app name.
bodystringNotification body text.
iconstringApp-root-relative image path. Defaults to the app icon.
silentbooleanSuppress the OS notification sound.
subtitlestringSecondary line below the title. macOS only.
urgency"normal" | "critical" | "low"Notification priority. Linux only.
timeoutType"default" | "never"Controls auto-dismiss. Linux and Windows only.

React to user interactions by listening for events on window:

window.addEventListener('notification:click', e => {
  console.log('clicked', e.detail.id);
});
window.addEventListener('notification:close', e => {
  console.log('dismissed', e.detail.id);
});
// macOS inline reply
window.addEventListener('notification:reply', e => {
  console.log(e.detail.id, e.detail.reply);
});
Event Fired when event.detail
notification:clickUser clicks the notification{ id }
notification:closeNotification is dismissed{ id }
notification:replyUser submits inline reply (macOS){ id, reply }

api.notification.isSupported()

Returns true if the current platform supports notifications.

const supported = await api.notification.isSupported();
if (supported) {
  api.notification.show({
    title: 'Hello'
  });
}

Utilities

api.getPlatform()

Returns the current OS: "mac", "win", or "linux". Useful for platform-specific UI or behavior.

const platform = await api.getPlatform();
// 'mac' | 'win' | 'linux'
if (platform === 'mac') {
  // macOS-specific behavior
}

api.getAppName()

Returns the app's display name as configured in kempo-app.appName.

const name = await api.getAppName();
document.title = name;
api.isDev()

Returns true when the app was started with --dev flag. Useful for showing debug UI or logging.

if (await api.isDev()) {
  console.log('Running in dev mode');
}
api.toggleDevTools()

Toggle the Chrome DevTools panel for the current window.

api.toggleDevTools();
