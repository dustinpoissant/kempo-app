Database

kempo-app provides two database options. Both store data in the OS user data directory and are available via api.

JSON Database

api.jsonDB — file-based key/value store. Each table is a separate JSON file. No setup required.
SQL Database

api.sqlDB — full SQL database powered by better-sqlite3. Requires npm install better-sqlite3.

Storage Location

Both databases store files in the same directory:

Platform Path
Windows%APPDATA%\<appName>\db\
macOS~/Library/Application Support/<appName>/db/
Linux~/.config/<appName>/db/

JSON tables are stored as *.json files, SQL databases as *.db files.
